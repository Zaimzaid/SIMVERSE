# SIMVERSE Visual Reference Pack

This pack is designed to be extracted directly into the root of the standalone `SIMVERSE` project.

After extraction, the important path is:

```text
docs/vision/
```

Claude Code should be told to inspect `docs/vision/VISION.md` and `docs/vision/references/` before designing the SIMVERSE UI.

## Important

- The images are **concept designs**, not screenshots of an existing application.
- They communicate product direction, visual language, information architecture, and long-term ambition.
- They do **not** authorize Claude Code to implement later phases early.
- Phase specifications always control implementation scope.
- Illustrative numbers, sample users, match scores, pricing, and fictional content shown in concept art are placeholders unless separately approved.

Start with `docs/vision/VISION.md`.
